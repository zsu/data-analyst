Agent Skill · Claude Code plugin · MIT

U.S. economic analysis skill for Claude and AI agents

data-analyst is an open-source Agent Skill for U.S. economic analysis, shipped as a plugin for Claude Code, Claude Desktop, claude.ai and Codex. It picks the federal sources a question needs (FRED, BLS, BEA, Census, Treasury, USAspending, CDC, Congress.gov, EPA and more), downloads the data, runs reproducible calculations, and returns audited CSVs and an HTML report.

View on GitHub Plugin catalog MCP server version

Install

Claude Code

/plugin marketplace add zsu/agent-plugins
/plugin install data-analyst@zsu

Codex

codex plugin marketplace add zsu/agent-plugins

Then install data-analyst from the Plugins directory. On Claude Desktop, Cowork and claude.ai, add the marketplace zsu/agent-plugins under Plugins. Any other assistant that reads Agent Skills can load the skill folder directly.

Questions it answers

  • How much has federal debt held by the public grown as a share of GDP since 2015?
  • Chart real average hourly earnings by industry over the last ten years.
  • How has the unemployment rate compared with CPI inflation since 2020?
  • How much did each federal agency spend in fiscal year 2024?

How it works

  1. Asks only the questions that change the answer: which measure, which years, which population.
  2. Fetches official series from the agency itself, with or without API keys; when a site refuses scripts it hands over a one-command manual download.
  3. Runs reproducible calculations and registers every number it cites.
  4. Audits the answer before release, and writes CSVs plus a short answer or an HTML report.

It never writes into its own folder, never prints or stores API keys in output, and never invents data.
